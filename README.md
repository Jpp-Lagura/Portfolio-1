# John Paul C. Lagura — Personal Portfolio

This website introduces John Paul C. Lagura, a BSIT student and aspiring web developer from Butuan City, Philippines. It highlights his background, skills, projects, and education, and provides contact links for professional connections. A photo gallery adds a personal touch.

The site is built with HTML, CSS, and vanilla JavaScript. It features a responsive layout, a light/dark theme toggle, mobile navigation, and sections that animate into view while scrolling. Portfolio content is loaded from a JSON data file.

## Run locally

The page uses `fetch()` to load its data, so open it through a local web server rather than directly as a file. For example, in VS Code, open the project folder and use the Live Server extension on `index.html`.

## Customize

- Edit `data/portfolio.json` to update the navigation, profile, skills, projects, education, contacts, and gallery.
- Add or replace images in `css/images/` and update their paths in the JSON file.
- Update the layout and appearance in `index.html` and `css/style.css`.
- Update interactive behavior in `js/script.js`.
